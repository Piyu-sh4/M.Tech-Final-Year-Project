# Course study guides, assessments and certificates

Build request 16 adds Java, React, Bootstrap, Tailwind CSS, Angular and MySQL foundations and the required Workforce Intelligence essentials course. The demo startup migration preserves existing enrollments and published assessments. JavaScript, Python and Docker courses gain study guides. The existing React course remains available with a skill link, study guide and assessment.

Course authors can link a skill without a video and can edit the study guide and practice assignment. The course catalog and My learning download the guide as a PDF. The download contains the practice assignment and course reference when available.

Learners open **My learning**, record 100% progress and select **Take assessment** on a course with a published assessment. Pass with at least 80%. The course checklist shows coursework progress, assessment readiness or completion and the current certificate status. Its entries reflect the saved course record after a refresh. Existing courses without an assessment retain the completion and review flow.

An independent HR or admin reviewer opens **Training certificate review**, finds the learner and selects **Issue certificate** on a ready record. The confirmation names both the learner and course. The review list shows when coursework, an assessment or a different reviewer is required. After issuance, the learner can download the branded certificate from My learning.

The required Workforce Intelligence course is listed in the catalog for enrollment. The required label records its training designation and does not block access to other modules.

## Record downloads

Registers that allow CSV export also offer **Export Excel**. Both formats include the records that match **Search records** across all pages of the register, using the same columns shown on screen. The Excel workbook is generated in the browser and opens in Excel. Individual records on supported registers can also be downloaded as editable Word documents. Certificate registers provide individual authorized PDF downloads.
