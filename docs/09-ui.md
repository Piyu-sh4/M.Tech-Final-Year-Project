# 🎨 UI Design System — Workforce Intelligence

## Design Principles
1. **Clarity** — Every element has a clear purpose; no decorative clutter
2. **Consistency** — Same patterns across all 121 pages
3. **Density** — Information-dense but not overwhelming (enterprise users)
4. **Speed** — Perceived performance via skeletons, instant feedback
5. **Accessibility** — Readable contrast, touch targets, keyboard nav

---
